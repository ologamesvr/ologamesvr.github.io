Privacy Policy

A draft of how we plan to handle data in Witch Shop Simulator.

DEVELOPMENT DRAFT — NOT READY FOR STORE SUBMISSION

The game is still in development. This draft describes the currently planned design. The release build’s data processing, protections for younger players, and backup settings must be confirmed before this becomes the published privacy policy.

Draft updated: 31 October 2026 · No effective date assigned

1. About this draft

Witch Shop Simulator is being developed by olo games for Meta Quest 3 and Meta Quest 3S. The currently planned game is a paid, single-player sandbox experience with no in-app purchases, chat, or microphone features.

This draft will be reviewed against the actual release build, including its Unity packages, platform integrations, and permissions. It is not a statement that every possible form of data processing has already been ruled out.

2. Planned game data

Progress and game settings are planned to be saved locally on the player’s headset so that play can continue between sessions. The developer does not currently plan to operate a server that receives these saves.

No third-party advertising, analytics, multiplayer, chat, or voice services are currently planned. Any platform identifiers or other data processed by the final build, including for checking access to the game, must be described here before release.

If you contact olo games by email, we receive your email address, the contents of your message, and any attachments you choose to send. We use this information to respond to your support or privacy request.

3. Save data and Meta Cloud Backup

Local saving and cloud backup are different features. If Meta Cloud Backup is enabled for the game and available to the player, Meta may back up supported save files and restore them after installation or when moving to another headset.

The game’s backup configuration has not yet been confirmed. The final policy will explain the actual arrangement and will not describe all saves as being stored exclusively on the device if platform backups are enabled.

Meta provides controls for managing cloud backups. Removing a local save or uninstalling a game does not necessarily remove an existing cloud backup. See Meta’s Cloud Backup information and Meta’s Cloud Backups page.

4. Purchases and platform services

The planned paid release will be distributed through the Meta Horizon Store. Purchases, platform accounts, and platform-operated features are subject to Meta’s own terms and privacy information. The final policy will also identify any data the game itself processes through Meta integrations.

See Meta’s Privacy Policy. Linking to that policy does not replace this game’s own privacy disclosures.

5. Retention and deletion

The final policy will explain how long relevant data is retained and how players can delete local progress and any applicable platform backups. It will also explain how to request deletion of any data held by olo games.

For questions or requests about information you have shared directly with olo games, contact ologamesvr@gmail.com. Instructions for deleting local saves and any applicable platform backups will be confirmed after the save system is finalized.

6. Intended audience

The Meta Quest version is intended for players aged 10 and over, including children aged 10–12, teens, and adults. This corresponds to Meta’s Mixed Ages audience category. Meta does not permit users under 10 on the Meta Horizon platform.

The official regional content ratings have not yet been assigned. The release build’s handling of age-category information and protections for younger players still need to be reviewed and described in the final policy.

7. This website

The supplied website does not include analytics scripts, advertising, tracking cookies, contact forms, or externally loaded fonts. If deployed using GitHub Pages, GitHub logs visitors’ IP addresses for security purposes as described in GitHub’s Pages documentation and GitHub’s Privacy Statement.

8. Contact and updates

For game support, privacy questions, or deletion requests, contact olo games at ologamesvr@gmail.com.

The final policy will include an effective date and any changes needed to match the released game.
